站点保持仅所有者可访问。第二阶段在原有自选、基础持仓、历史净值研究、归档、JSON 导出和 PWA 之上，增加资产映射、相关市场行情、盘前条件报告、事件解释与正式净值复盘。对应 Sites source commit `af8bdd464d676fc93bea7949e8533ed3f1da1603`，已发布版本 3。此目录是完整 Sites 源码的 GitHub 镜像；原 Python/FastAPI、React 和 SwiftUI 继续保留，完整 Python 风险/预测/回测引擎尚未迁云。

## 使用

1. 用站点所有者的 ChatGPT 账户登录，添加六位基金代码到自选，核对名称、份额类别与正式净值日期。
2. 在“盘前决策”选择基金，打开“编辑映射与费用”，填写持仓或代理资产、权重、披露/发布日期、来源及持有期限。可记录份额、分批赎回与手动确认的费率。
3. 查看对应沪深股票、ETF、指数的真实分钟走势和日 K 线。基金本身仍展示正式净值曲线。
4. 生成盘中快照，查看今日净值情景、后续风险、费用约束三个问题。每份快照冻结当时可获得的数据、映射、持仓和相关事件，历史快照不会因刷新而覆盖。
5. 晚间取得同日正式净值后查看估值误差；5/20 个后续净值观察满足时再计算声明方案的假设扣费比较。存在分红等影响时暂停未复权收益比较。

## 模型边界

覆盖不足、行情延迟/缺失、披露陈旧、映射或基准净值在截止时刻后才可得时，系统不会输出完整基金净值情景。QDII、债基及未知类型不套用 A 股日内加权模型；当前资产行情仅支持沪深。

估值是“剩余时段资产价格不变”的情景，不是已验证收盘预测。不显示虚构置信区间或买卖成功率。资产5/20日走势、均线、亏损阈值与事件提供条件解释，没有证明未来超额收益。新闻的事实、解释和反向可能分开显示，后见事件不回填旧报告。

费用为用户手动确认的情景，尚未自动核验基金合同与平台费率；假设比较不是实际成交收益。正式净值仍为第三方数据，未完成独立双源核验。自动交易关闭。完整 Python 模型、截图识别、海外/债券适配、精确费用核验与价格数据授权仍属于后续工作。
